# 相信科学 · 用数据科学检验传统命理学的预测效度

> 一个"心理学 × 数据科学"的独立项目：从公众号文章爬取真实样本，人工标注社会经济成就量尺，用 KNN / 逻辑回归 / XGBoost 等模型实证检验"八字"对人生成就的预测效力。
>
> **项目立场：不做预测工具，做一次诚实的科学检验。** 多模型结果均显示传统命理特征的预测效力有限——相信数据，相信科学。

---

## 项目动机 / Motivation

"八字"是流传千年的传统命题：出生时间的干支组合（年柱、月柱、日柱、时柱 × 天干地支）据说能预测人一生的命运。

心理学训练教会我两件事：**任何"测量工具"都要检验效度（criterion validity）；任何结论都要靠数据说话。** 于是有了这个项目——用标准的机器学习流程，检验"命理特征能否预测人生成就"。

## 数据管线 / Pipeline

```
公众号命理文章（大龙盲派专辑）
        │  Ⅰ爬虫爬取数据.py（Requests + XPath + 正则，翻页抓取 + 评语正文提取）
        ▼
网页汇总.txt → 样本提取（正则抽取 乾坤+四柱干支）
        │  手动数据录入.py auto_in()（自动编码入库）+ Ⅱ爬取数据后去重.py
        ▼
八字自动录入数据.csv（155 条，其中 51 条已评分）
        │  人工标注：1–12 分社会经济成就量尺（1–2 早夭 / 3–5 温饱 / 6 普通 / 7–9 非普通人 / 10–12 佼佼者）
        ▼
八字数据.csv（手工 232 条，全部含标签与评语）
        │  特征工程：天干(1–10)、地支(1–12)、性别 类别编码 → OneHot
        ▼
多模型效度检验：KNN / 逻辑回归 / XGBoost / 朴素贝叶斯 + 网格搜索 + 交叉验证
```

## 文件说明 / Files

| 脚本 | 作用 |
| --- | --- |
| `Ⅰ爬虫爬取数据.py` | 微信公众平台相册接口翻页爬取文章链接，逐篇抓取正文，正则提取八字样本并入库 |
| `Ⅱ爬取数据后去重.py` | 按评语去重，保证样本唯一性 |
| `Ⅲ切词自动打分.py` | jieba 分词 + 词频向量化，朴素贝叶斯 / XGBoost 尝试评语自动打分（探索性） |
| `Ⅳknn模型.py` | KNN 分类 + GridSearchCV 网格搜索（n_neighbors 3–10） |
| `Ⅴ逻辑回归.py` | 逻辑回归（class_weight='balanced' 处理类别不平衡） |
| `Ⅵxgboost.py` | XGBoost 多分类 + 样本权重平衡 |
| `手动数据录入.py` | 交互式人工录入 + 爬虫自动录入（八字 → 天干地支数值编码） |
| `数据处理+模型训练(测试).py` | 多模型探索（线性回归 / 决策树 / AdaBoost / GBDT / XGBoost） |
| `数据查询.py` | 查看标签分布与数据规模 |

## 数据集 / Dataset

- 手工标注：`data/八字数据.csv`（**232 条**，含 1–12 分标签与命理评语）
- 爬虫采集：`data/八字自动录入数据.csv`（**155 条**，104 条未评分 / 51 条已评分）
- 停用词表：`data/stopwords.txt`
- 标签分布：4–8 分（普通人区间）占比最高，极端高分/低分样本稀少——**类别不平衡是该项目的主要局限之一**

## 技术栈 / Tech Stack

- 数据采集：`requests` + `lxml`（XPath）+ `re`
- 数据处理：Pandas / NumPy
- 机器学习：Scikit-learn（KNN / LogisticRegression / MultinomialNB / GridSearchCV）、XGBoost
- 文本挖掘：jieba + CountVectorizer（探索性）

## 局限与反思 / Limitations

1. **样本量小**（约 300 条原始样本，有效标注约 150+）——统计功效有限。
2. **标注主观性**：社会经济成就量尺依赖人工判断，标注者偏差不可避免。
3. **类别不平衡**：极端成就样本稀少，模型对少数类学习困难。
4. **结论**：在现有数据与特征下，命理特征对人生成就的预测效力有限。**这正是"相信科学"的含义：让数据说话，而不是让信念说话。**

## 运行 / Quick Start

```bash
pip install -r requirements.txt   # 见上级目录（pandas/sklearn/xgboost/jieba/lxml/requests）
python 手动数据录入.py            # 人工录入（或运行 Ⅰ爬虫爬取数据.py 自动采集）
python Ⅳknn模型.py / Ⅴ逻辑回归.py / Ⅵxgboost.py
```
